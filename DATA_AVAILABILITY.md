# Data and code availability

This release provides source code and aggregate numerical summaries only. The original analysis used publicly visible online discussions, but the research compilation contains row-level posts, linked identifiers, author-group membership, and human-review decisions that are not redistributed through this release. Some raw material is also governed by platform-access terms and institutional ethics arrangements.

**Not supplied publicly:** full Reddit texts; original post IDs or URLs; pseudonymised author groups; labels/reviewer notes on individual posts; private candidate lists; per-post or per-fold OOF predictions; source corpora; authentication credentials; model caches; human-review workbooks; original notebook execution outputs.

**Available:** an output-free, syntax-checked computational source notebook and model-level summaries. Full replication requires authorised access to protected research inputs, compatible compute resources and the pinned model revision. The researchers retain responsibility for the interpretation of the analyses. Scientific conclusions should be interpreted as post-level exploratory candidate identification and not as clinical validation.
